Lektion 5: Interaktion ​

Lernziel ​

Dein Bot versteht Befehle, zeigt Tastaturen und reagiert auf Tastendrücke. Du kannst Befehle bei Telegram anmelden, in Nachrichten erkennen, eine Antwort-Tastatur und Inline-Tasten senden und Klicks korrekt beantworten.

Ab dieser Lektion nutzen die Beispiele das gemeinsame Modul apps/telegram-client. Es enthält die Klasse BotApi aus Lektion 2 (jetzt TelegramClient), den UpdatePoller aus Lektion 3 und neu die Klasse Tastaturen. Die Anwendungen dieser Lektion sind der Echo- und Befehls-Bot in apps/echo-befehls-bot und am Ende der Quiz-Bot in apps/quiz-bot.

Erklärung ​

Befehle. Ein Befehl ist ein Wort mit Schrägstrich am Anfang einer Nachricht, zum Beispiel /hilfe. Er hat bis zu 32 Zeichen aus Buchstaben, Ziffern und Unterstrichen, am besten klein geschrieben. Telegram hebt Befehle in Nachrichten hervor, ein Tipp darauf sendet sie sofort. Hast du eine Liste angemeldet, schlägt der Client sie vor, sobald der Nutzer / tippt.

  • Anmelden mit setMyCommands: eine Liste von BotCommand mit command (1 bis 32 Zeichen, nur Kleinbuchstaben, Ziffern und Unterstriche) und description (1 bis 256 Zeichen), höchstens 100 Stück. Optional scope (andere Befehle für Gruppen oder Admins) und language_code. Mit getMyCommands liest du die Liste, mit deleteMyCommands löschst du sie.
  • Erkennen: Telegram markiert den Befehl in message.entities als Eintrag vom Typ bot_command mit offset 0 und length. In Gruppen kann er an einen Bot gerichtet sein: /hilfe@mein_bot. Befehle an andere Bots ignorierst du, auch als Text spiegeln solltest du sie nicht.
  • Globale Befehle: Telegram bittet alle Bots, /start (Begrüßung) und /help (Hilfe) zu unterstützen, und bei Einstellungen /settings. Der Beispiel-Bot kennt /hilfe und nimmt /help als Alias.

Deep Links. Jeder Bot hat die Adresse https://t.me/<bot_username>. Hängst du ?start=airplane an, empfängt dein Bot beim Öffnen die Nachricht /start airplane. So übergibst du Parameter an den Bot, etwa eine Kampagne oder ein Einmal-Token. Erlaubt sind A-Z, a-z, 0-9, _ und -, bis zu 64 Zeichen. In Gruppen funktioniert ?startgroup=….

Antwort-Tastatur (Reply Keyboard). Ersetzt die Buchstabentastatur durch Tasten. Ein Druck sendet den Text der Taste als normale Nachricht, dein Bot sieht also nur Text. Das Objekt ReplyKeyboardMarkup hat keyboard (Zeilen von Tasten) und Optionen wie resize_keyboard, one_time_keyboard und input_field_placeholder. Mit ReplyKeyboardRemove (remove_keyboard: true) blendest du sie aus. Die Tastatur bleibt, bis du eine neue sendest oder sie entfernst.

Inline-Tasten (Inline Keyboard). Hängen direkt an einer Nachricht. Das Objekt InlineKeyboardMarkup hat inline_keyboard (Zeilen von Tasten). Jede Taste hat text und genau eine Aktion:

FeldWirkung
callback_datasendet dir ein Update callback_query. Die Daten sind 1 bis 64 Bytes lang (Bytes, nicht Zeichen: ein ä zählt doppelt).
urlöffnet einen Link, ohne dass dein Bot etwas erfährt
web_appstartet eine Mini App (Lektion 11)
switch_inline_querywechselt in den Inline-Modus (Lektion 9)

Klicks beantworten. Drückt jemand eine callback_data-Taste, bekommst du ein Update callback_query mit id, from (wer geklickt hat), data und message (die Nachricht mit der Taste). Der Client zeigt an der Taste einen Ladebalken, bis du answerCallbackQuery aufrufst. Rufe es immer auf, auch wenn du dem Nutzer nichts mitteilen willst. Parameter: callback_query_id (Pflicht), text (bis 200 Zeichen, erscheint oben als Hinweis), show_alert (als Dialog statt Hinweis) und cache_time.

Unterschiede zwischen den Tastaturen und Fallen:

FrageAntwort-TastaturInline-Tasten
Was kommt beim Bot an?Nachricht mit dem Text der Tastecallback_query mit data
Wo steht sie?statt der Buchstabentastaturan der Nachricht
Beantworten nötig?neinja, mit answerCallbackQuery
  • Alte Nachrichten behalten ihre Tasten. Nach einem Neustart oder einer Programmänderung können Klicks mit data ankommen, die der Bot nicht mehr kennt. Beantworte sie trotzdem, am besten mit einem Hinweis. Behandle callback_data wie jede Eingabe: Sie ist nur so zuverlässig wie dein Code, der sie erzeugt.
  • Der Zähler im Beispiel liegt im Speicher und ist nach einem Neustart weg. Dauerhafte Daten bräuchten eine Datenbank, siehe das Spring-Kapitel.
  • Pro Token darf nur ein Programm getUpdates aufrufen. Läuft dein Bot noch in einem anderen Terminal, bekommst du einen Fehler 409.

Methoden dieser Lektion

  • sendPoll (Orte, Kontakte, Umfragen, Checklisten)
  • answerCallbackQuery (Interaktion und Nutzerinfos (Callbacks, Befehle, Menü, Profile))
  • setMyCommands (Interaktion und Nutzerinfos (Callbacks, Befehle, Menü, Profile))
  • deleteMyCommands (Interaktion und Nutzerinfos (Callbacks, Befehle, Menü, Profile))
  • getMyCommands (Interaktion und Nutzerinfos (Callbacks, Befehle, Menü, Profile))

Java ​

Tastaturen bauen. Die Klasse Tastaturen im Modul telegram-client erzeugt die reply_markup-Objekte. Ihr Ergebnis steckst du in den Parameter reply_markup von sendMessage. Die Inline-Tasten prüfen, dass callback_data höchstens 64 Bytes hat und dass genau eine Aktion gesetzt ist:

java
/** Tasten direkt unter der Nachricht. Ein Klick auf eine {@code callback_data}-Taste erzeugt ein Update. */
public static ObjectNode inline(List<List<Taste>> zeilen) {
    ObjectNode markup = JSON.createObjectNode();
    ArrayNode alleZeilen = markup.putArray("inline_keyboard");
    for (List<Taste> zeile : zeilen) {
        ArrayNode json = alleZeilen.addArray();
        for (Taste taste : zeile) {
            ObjectNode knopf = json.addObject().put("text", taste.text());
            if (taste.callbackData() != null) {
                knopf.put("callback_data", taste.callbackData());
            } else if (taste.url() != null) {
                knopf.put("url", taste.url());
            } else if (taste.inlineAbfrage() != null) {
                knopf.put("switch_inline_query", taste.inlineAbfrage());
            } else {
                knopf.put("switch_inline_query_current_chat", taste.inlineAbfrageHier());
            }
        }
    }
    return markup;
}
java
/** Tastatur anstelle der Buchstabentastatur. Ein Druck sendet den Text der Taste als normale Nachricht. */
public static ObjectNode antwort(List<List<String>> zeilen) {
    ObjectNode markup = JSON.createObjectNode();
    ArrayNode alleZeilen = markup.putArray("keyboard");
    for (List<String> zeile : zeilen) {
        ArrayNode json = alleZeilen.addArray();
        zeile.forEach(text -> json.addObject().put("text", text));
    }
    markup.put("resize_keyboard", true);
    return markup;
}

/** Meldet die Befehle bei Telegram an, damit der Client sie nach einem "/" vorschlägt. */
void befehleRegistrieren() throws IOException, InterruptedException {
    ObjectNode parameter = TelegramClient.parameter();
    ArrayNode liste = parameter.putArray("commands");
    for (BefehlInfo befehl : BEFEHLE) {
        liste.addObject().put("command", befehl.name()).put("description", befehl.beschreibung());
    }
    client.aufrufen("setMyCommands", parameter);
}

Befehle erkennen. Die Klasse Befehl (im Modul telegram-client, damit auch spätere Bots sie nutzen) liest die Entität bot_command. Sie unterscheidet „Befehl an mich", „Befehl an einen anderen Bot" und „kein Befehl":

java
/** Beginnt die Nachricht mit einem Befehl, egal an welchen Bot er gerichtet ist? */
public static boolean beginntMitBefehl(JsonNode nachricht) {
    for (JsonNode entitaet : nachricht.path("entities")) {
        if (entitaet.path("type").asText().equals("bot_command") && entitaet.path("offset").asInt() == 0) {
            return true;
        }
    }
    return false;
}

/**
 * Telegram markiert Befehle als Entität {@code bot_command}. In Gruppen kann ein Befehl mit {@code @botname}
 * an einen bestimmten Bot gerichtet sein. Ist er an einen anderen Bot gerichtet, ist das Ergebnis leer.
 */
public static Optional<Befehl> aus(JsonNode nachricht, String eigenerName) {
    if (!beginntMitBefehl(nachricht)) {
        return Optional.empty();
    }
    String text = nachricht.path("text").asText("");
    int laenge = nachricht.path("entities").get(0).path("length").asInt();
    String wort = text.substring(1, laenge);
    int at = wort.indexOf('@');
    if (at >= 0) {
        if (!wort.substring(at + 1).equalsIgnoreCase(eigenerName)) {
            return Optional.empty();
        }
        wort = wort.substring(0, at);
    }
    return Optional.of(new Befehl(wort.toLowerCase(Locale.ROOT), text.substring(laenge).trim()));
}

Verteilen. Befehle laufen in eine switch-Anweisung, Text ohne Befehl wird gespiegelt, Befehle an andere Bots bleiben unbeantwortet:

java
private void nachricht(JsonNode nachricht) throws IOException, InterruptedException {
    long chatId = nachricht.path("chat").path("id").asLong();
    Optional<Befehl> befehl = Befehl.aus(nachricht, eigenerName);
    if (befehl.isPresent()) {
        befehlAusfuehren(chatId, befehl.get());
    } else if (Befehl.beginntMitBefehl(nachricht)) {
        // Befehl an einen anderen Bot (z. B. /hilfe@anderer_bot in einer Gruppe): nicht antworten.
    } else if (nachricht.has("text")) {
        senden(chatId, nachricht.get("text").asText());
    }
}

private void befehlAusfuehren(long chatId, Befehl befehl) throws IOException, InterruptedException {
    switch (befehl.name()) {
        case "start" -> senden(chatId, begruessung(befehl.argumente()));
        // /help ist einer der globalen Befehle, um die Telegram bittet. Registriert ist nur /hilfe.
        case "hilfe", "help" -> senden(chatId, hilfetext());
        case "echo" -> senden(chatId, befehl.argumente().isEmpty() ? "Benutzung: /echo <Text>" : befehl.argumente());
        case "menue" -> menueSenden(chatId);
        case "tastatur" -> tastaturSenden(chatId);
        case "aus" -> tastaturEntfernen(chatId);
        default -> senden(chatId, "Diesen Befehl kenne ich nicht: /" + befehl.name() + ". /hilfe zeigt alle Befehle.");
    }
}

private void menueSenden(long chatId) throws IOException, InterruptedException {
    ObjectNode parameter = nachrichtParameter(chatId, "Was möchtest du tun?");
    parameter.set("reply_markup", Tastaturen.inline(List.of(
            List.of(Taste.daten("Zählen", "zaehlen"), Taste.daten("Zurücksetzen", "reset")),
            List.of(Taste.daten("Hilfe", "hilfe")),
            List.of(Taste.link("Doku öffnen", "https://core.telegram.org/bots/api")))));
    client.aufrufen("sendMessage", parameter);
}

private void callback(JsonNode abfrage) throws IOException, InterruptedException {
    long nutzer = abfrage.path("from").path("id").asLong();
    ObjectNode antwort = TelegramClient.parameter().put("callback_query_id", abfrage.path("id").asText());
    switch (abfrage.path("data").asText()) {
        case "zaehlen" -> antwort.put("text", "Zähler: " + zaehler.merge(nutzer, 1, Integer::sum));
        case "reset" -> {
            zaehler.remove(nutzer);
            antwort.put("text", "Zähler zurückgesetzt");
        }
        case "hilfe" -> antwort.put("text", kurzhilfe()).put("show_alert", true);
        default -> antwort.put("text", "Diese Taste ist veraltet.");
    }
    // Immer beantworten, sonst zeigt der Client weiter einen Ladebalken an der Taste.
    client.aufrufen("answerCallbackQuery", antwort);
}

Übung ​

Baue eine Ja/Nein-Frage: Der Bot sendet „Gefällt dir die Lektion?" mit den Tasten „Ja" und „Nein". Jeder Klick wird mit einem Hinweis beantwortet („Du hast Ja gewählt"), auch der Klick auf eine veraltete Taste.

Lösung
java
static void frageSenden(TelegramClient client, long chatId) throws IOException, InterruptedException {
    ObjectNode parameter = TelegramClient.parameter().put("chat_id", chatId).put("text", "Gefällt dir die Lektion?");
    parameter.set("reply_markup", Tastaturen.inline(List.of(
            List.of(Taste.daten("Ja", "antwort:ja"), Taste.daten("Nein", "antwort:nein")))));
    client.aufrufen("sendMessage", parameter);
}

static void klickBeantworten(TelegramClient client, JsonNode abfrage) throws IOException, InterruptedException {
    String text = switch (abfrage.path("data").asText()) {
        case "antwort:ja" -> "Du hast Ja gewählt";
        case "antwort:nein" -> "Du hast Nein gewählt";
        default -> "Diese Taste ist veraltet.";
    };
    client.aufrufen("answerCallbackQuery",
            TelegramClient.parameter().put("callback_query_id", abfrage.path("id").asText()).put("text", text));
}

Anwendung: Quiz-Bot ​

Der zweite Bot dieser Lektion stellt Quizfragen, zählt Punkte und zeigt eine Bestenliste (apps/quiz-bot). Er verbindet Umfragen mit dem, was du über Inline-Tasten weißt.

Quiz-Umfrage. Mit sendPoll und type: "quiz" schickst du eine Umfrage, bei der es eine richtige Antwort gibt. Wichtig sind diese Parameter:

ParameterBedeutung
questiondie Frage, 1 bis 300 Zeichen
optionsListe von Objekten {"text": "…"}, je 1 bis 100 Zeichen. Die Doku nennt 1 bis 12 Antworten, das Beispiel verlangt mindestens 2, sonst wäre die Frage witzlos.
correct_option_idsListe der richtigen Positionen, 0-basiert. Bei einer Quizfrage mit einer Lösung genau ein Eintrag. Ältere Beispiele im Netz kennen noch correct_option_id (Einzahl), die aktuelle Doku nennt nur die Liste.
explanationText, den der Client nach einer falschen Antwort oder beim Tippen auf die Glühbirne zeigt, bis 200 Zeichen
is_anonymousfalse, sonst erfährt dein Bot nicht, wer geantwortet hat (siehe unten). Standard ist true.
reply_markupauch an einer Umfrage kannst du Inline-Tasten anbringen, hier „Nächste Frage"

Bei einem Quiz kann ein Nutzer seine Antwort standardmäßig nicht ändern (allows_revoting ist für Quizze false).

Antworten empfangen. Jede Stimme in einer nicht anonymen Umfrage erzeugt ein Update poll_answer. Es enthält poll_id, user (wer geantwortet hat) und option_ids (die gewählten Positionen, bei einer zurückgezogenen Stimme leer). Drei Dinge musst du beachten:

  • Fordere poll_answer in allowed_updates an, sonst kommt es nicht.
  • Du bekommst Stimmen nur in Umfragen, die dein Bot selbst gesendet hat.
  • Das Update enthält keine Chat-ID, nur die poll_id. Merke dir deshalb beim Senden, welche Umfrage in welchem Chat steht. Die Antwort von sendPoll ist die gesendete Nachricht, die ID steht in poll.id. Antwortet jemand anonym als Gruppe oder Kanal, steht statt user das Feld voter_chat im Update, das Beispiel ignoriert solche Stimmen.
java
/** Sendet eine Frage als Quiz-Umfrage mit einer Taste für die nächste Frage (oder das Ergebnis). */
void frageStellen(long chatId, int nummer) throws IOException, InterruptedException {
    Frage frage = fragen.get(nummer);
    ObjectNode parameter = TelegramClient.parameter()
            .put("chat_id", chatId)
            .put("question", "(" + (nummer + 1) + "/" + fragen.size() + ") " + frage.text())
            .put("type", "quiz")
            // Nur in nicht anonymen Umfragen erfährt der Bot, wer wie geantwortet hat.
            .put("is_anonymous", false)
            .put("explanation", frage.erklaerung());
    parameter.putArray("correct_option_ids").add(frage.richtig());
    for (String option : frage.optionen()) {
        parameter.withArray("options").addObject().put("text", option);
    }
    boolean letzte = nummer == fragen.size() - 1;
    Taste taste = letzte ? Taste.daten("Ergebnis anzeigen", "ergebnis") : Taste.daten("Nächste Frage", "weiter:" + (nummer + 1));
    parameter.set("reply_markup", Tastaturen.inline(List.of(List.of(taste))));

    JsonNode nachricht = client.aufrufen("sendPoll", parameter);
    // Die Antwort enthält die Umfrage mit ihrer ID: darüber ordnen wir spätere Antworten zu.
    gestellt.put(nachricht.path("poll").path("id").asText(), new Gestellt(chatId, nummer));
    letzteFrage.put(chatId, nummer);
}
java
/** Ein Nutzer hat in einer Umfrage des Bots geantwortet. */
private void antwort(JsonNode abstimmung) {
    String pollId = abstimmung.path("poll_id").asText();
    Gestellt ziel = gestellt.get(pollId);
    JsonNode nutzer = abstimmung.path("user");
    JsonNode gewaehlt = abstimmung.path("option_ids");
    // Unbekannte Umfrage (z. B. von vor einem Neustart), anonymer Absender (nur voter_chat) oder zurückgezogene Stimme.
    if (ziel == null || !nutzer.has("id") || gewaehlt.isEmpty()) {
        return;
    }
    long nutzerId = nutzer.get("id").asLong();
    if (!gewertet.add(pollId + ":" + nutzerId)) {
        return;
    }
    boolean richtig = gewaehlt.size() == 1 && gewaehlt.get(0).asInt() == fragen.get(ziel.frage()).richtig();
    Spieler spieler = punkte.computeIfAbsent(ziel.chatId(), c -> new ConcurrentHashMap<>())
            .computeIfAbsent(nutzerId, id -> new Spieler(anzeigename(nutzer)));
    synchronized (spieler) {
        spieler.antworten++;
        if (richtig) {
            spieler.richtig++;
        }
    }
}

Das Beispiel prüft drei Fälle, in denen es nichts zählt: eine unbekannte Umfrage (etwa von vor einem Neustart), eine zurückgezogene Stimme und einen anonymen Absender. Jede Antwort zählt außerdem nur einmal. Mehrere richtige Antworten gibt es bei den Fragen des Beispiels nicht, eine Stimme mit mehreren Positionen gilt darum als falsch.

„Nächste Frage" ohne doppelte Fragen. Die Taste unter der Umfrage trägt die Nummer der nächsten Frage in callback_data (weiter:2). In einer Gruppe können mehrere Leute gleichzeitig tippen. Der Bot stellt die Frage deshalb nur, wenn die Nummer zur zuletzt gestellten Frage dieses Chats passt. Jeder weitere Klick bekommt nur einen Hinweis. Die letzte Frage hat statt der Taste „Nächste Frage" die Taste „Ergebnis anzeigen".

java
private void klick(JsonNode abfrage) throws IOException, InterruptedException {
    ObjectNode antwort = TelegramClient.parameter().put("callback_query_id", abfrage.path("id").asText());
    JsonNode chat = abfrage.path("message").path("chat");
    String daten = abfrage.path("data").asText();
    String hinweis = null;
    if (!chat.has("id")) {
        hinweis = "Diese Taste ist veraltet.";
    } else if (daten.equals("ergebnis")) {
        senden(chat.get("id").asLong(), bestenliste(chat.get("id").asLong()));
    } else if (daten.startsWith("weiter:")) {
        hinweis = weiter(chat.get("id").asLong(), daten.substring("weiter:".length()));
    } else {
        hinweis = "Diese Taste ist veraltet.";
    }
    if (hinweis != null) {
        antwort.put("text", hinweis);
    }
    // Immer beantworten, sonst zeigt der Client weiter einen Ladebalken an der Taste.
    client.aufrufen("answerCallbackQuery", antwort);
}

/** Stellt die nächste Frage, aber nur einmal: der Klick muss zur zuletzt gestellten Frage passen. */
private String weiter(long chatId, String nummerText) throws IOException, InterruptedException {
    int nummer;
    try {
        nummer = Integer.parseInt(nummerText);
    } catch (NumberFormatException e) {
        return "Diese Taste ist veraltet.";
    }
    Integer zuletzt = letzteFrage.get(chatId);
    if (nummer < 1 || nummer >= fragen.size() || zuletzt == null || zuletzt != nummer - 1) {
        return "Diese Frage wurde schon gestellt. /quiz startet eine neue Runde.";
    }
    frageStellen(chatId, nummer);
    return null;
}

Bestenliste. Die Punkte liegen pro Chat und Nutzer im Arbeitsspeicher. Sortiert wird nach richtigen Antworten, dann nach weniger Versuchen, dann nach Name:

java
/** Die besten Spieler dieses Chats: erst nach richtigen Antworten, dann nach weniger Versuchen, dann nach Name. */
String bestenliste(long chatId) {
    Map<Long, Spieler> spieler = punkte.getOrDefault(chatId, Map.of());
    if (spieler.isEmpty()) {
        return "Noch keine Antworten. /quiz startet eine Runde.";
    }
    List<Spieler> sortiert = new ArrayList<>(spieler.values());
    sortiert.sort(Comparator.<Spieler>comparingInt(s -> -s.richtig)
            .thenComparingInt(s -> s.antworten)
            .thenComparing(s -> s.name));
    StringBuilder text = new StringBuilder("Bestenliste");
    int platz = 1;
    for (Spieler s : sortiert.subList(0, Math.min(BESTENLISTE, sortiert.size()))) {
        text.append('\n').append(platz++).append(". ").append(s.name)
                .append(": ").append(s.richtig).append(" von ").append(s.antworten).append(" richtig");
    }
    return text.toString();
}

Schicke /quiz, beantworte eine Frage richtig und eine falsch (achte auf die Erklärung), tippe auf „Nächste Frage" und danach mehrmals schnell auf dieselbe Taste. Am Ende zeigen „Ergebnis anzeigen" oder /rangliste die Bestenliste. Lade danach einen Freund oder einen zweiten Account ein: In einer Gruppe zählt jede Person einzeln.

Die Tests laufen ohne Telegram gegen den Fake:

bash
./mvnw -q verify -pl apps/quiz-bot -am
