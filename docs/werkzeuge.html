Werkzeuge ​

Diese Seite stellt Programme vor, die du außerhalb von Java brauchst. Bisher ist das eines: cloudflared, das deinen Rechner für Telegram per HTTPS erreichbar macht.

cloudflared: eine öffentliche HTTPS-Adresse für deinen Rechner ​

Wozu brauchst du das? ​

Zwei Teile dieses Kurses verlangen eine Adresse, die Telegram aus dem Internet aufrufen kann:

  • Webhooks (Lektion 6): Telegram schickt Updates an eine URL. Dabei ist das Ausprobieren optional.
  • Mini Apps (Lektion 11): Der Telegram-Client lädt deine Webseite von einer URL. Hier ist der Live-Lauf Pflicht.

Beides geht nur über HTTPS. Dein Rechner steht aber meist hinter einem Router und einer Firewall, hat keine feste öffentliche Adresse und kein Zertifikat. Du könntest einen Server mit Domain mieten oder den Router einrichten. Für das Lernen ist das zu viel Aufwand.

Was macht cloudflared? ​

cloudflared ist ein kleines Programm von Cloudflare, die Software für den Dienst Cloudflare Tunnel. Es läuft auf deinem Rechner und baut von dort eine ausgehende Verbindung zum Netz von Cloudflare auf. Cloudflare nimmt Anfragen unter einer öffentlichen HTTPS-Adresse entgegen und reicht sie durch diese Verbindung an einen Port auf deinem Rechner weiter. Weil die Verbindung von innen nach außen aufgebaut wird, musst du an Router und Firewall nichts freigeben.

text
Telegram-App oder Telegram-Server
        |  HTTPS
        v
https://<zufall>.trycloudflare.com      (Cloudflare, nimmt die Anfragen an)
        |  durch die Verbindung, die cloudflared von deinem Rechner aufgebaut hat
        v
cloudflared  -->  http://localhost:8080   (dein Java-Programm)

Dein Java-Programm spricht nur gewöhnliches HTTP auf localhost. Das HTTPS endet bei Cloudflare, so wie bei einem Reverse Proxy.

Quick-Tunnel: ohne Konto ​

Für den Kurs genügt der Quick-Tunnel. Er braucht weder ein Cloudflare-Konto noch eine eigene Domain:

bash
cloudflared tunnel --url http://localhost:8080

In der Ausgabe steht eine Adresse wie https://<zufall>.trycloudflare.com. Sie leitet auf den angegebenen Port. Das Programm bleibt im Vordergrund: Lass das Terminal offen, beende den Tunnel mit Strg+C.

Wichtig zu wissen (nach der Doku von Cloudflare):

  • Die Adresse ist temporär. Sie funktioniert nur, solange cloudflared läuft, und ist bei jedem Start eine andere. Deshalb setzt das Mini-App-Beispiel die Menütaste bei jedem Start neu, und du setzt MINI_APP_URL jedes Mal neu.
  • Jeder, der die Adresse kennt, erreicht deinen lokalen Dienst. Gib sie nicht weiter und lass den Tunnel nicht länger offen als nötig.
  • Quick-Tunnels sind für Tests und Entwicklung gedacht, nicht für den Betrieb. Es gibt keine Garantie für die Verfügbarkeit, höchstens 200 gleichzeitige Anfragen (weitere bekommen einen 429) und keine Server-Sent Events.
  • Die Option --allowed-mail schützt eine Adresse mit einem Code per E-Mail. Sie verlangt eine Anmeldung im Browser und ist darum für Telegram nicht brauchbar: Die Server von Telegram, die einen Webhook aufrufen, können sich nicht per E-Mail anmelden.
  • Der Datenverkehr läuft über das Netz von Cloudflare. Schicke über den Tunnel nichts, was dort nicht durchlaufen soll.

Für eine feste Adresse und den Dauerbetrieb gibt es den Cloudflare Tunnel mit Konto und Domain. Das ist nicht Teil dieses Kurses, die Doku erklärt es.

Installieren ​

Die Downloadseite von Cloudflare führt alle Wege auf. Das Programm ist Open Source (Apache-2.0) und wird von Cloudflare auf GitHub gepflegt.

SystemWeg
LinuxPaketquelle von Cloudflare (pkg.cloudflare.com), oder .deb, .rpm oder eine einzelne Programmdatei von der GitHub-Releaseseite
macOSbrew install cloudflared, oder ein Download von GitHub
Windows.exe oder .msi von der GitHub-Releaseseite. Unter Windows aktualisiert sich das Programm nicht selbst.
DockerImage cloudflare/cloudflared auf Docker Hub

Ubuntu und Debian. Zwei Wege, beide mit sudo. Welche Ubuntu-Version du hast, zeigt lsb_release -a.

Weg 1: Paketquelle von Cloudflare (empfohlen). Sie liefert auch spätere Aktualisierungen über apt. Die Befehle stammen von pkg.cloudflare.com, Abschnitt „Any Debian Based Distribution". Sie gelten für Ubuntu 20.04, 22.04 und 24.04 gleichermaßen:

bash
# Schlüssel zum Prüfen der Pakete ablegen
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null

# Paketquelle (stabile Version) eintragen
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list

# installieren
sudo apt-get update && sudo apt-get install cloudflared

Cloudflare hat Ende Oktober 2025 den Signaturschlüssel getauscht. Nimm deshalb immer die Befehle von der Seite von Cloudflare, wenn sich etwas an diesen Zeilen ändert. Später aktualisierst du mit sudo apt-get update && sudo apt-get install --only-upgrade cloudflared.

Weg 2: einzelnes .deb-Paket von GitHub. Das ist ein Download ohne Paketquelle, Aktualisierungen musst du selbst holen. Die Architektur zeigt dpkg --print-architecture (amd64 oder arm64):

bash
# amd64 (die meisten PCs und Laptops)
curl -fL -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
# arm64 stattdessen:
# curl -fL -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb

sudo dpkg -i cloudflared.deb
rm cloudflared.deb

Unter Ubuntu in WSL gelten dieselben Befehle.

Prüfen, ob es installiert ist:

bash
cloudflared --version

Unter WSL (Windows) installierst du die Linux-Version innerhalb von WSL, damit der Tunnel auf denselben localhost zeigt wie dein Java-Programm.

So benutzt du ihn im Kurs ​

  1. In einem eigenen Terminal den Tunnel starten und die Adresse notieren:
    bash
    cloudflared tunnel --url http://localhost:8080
  2. In einem zweiten Terminal das Beispiel mit dieser Adresse starten (zum Beispiel MINI_APP_URL in Lektion 11 oder WEBHOOK_URL in Lektion 6).
  3. Der Port hinter --url muss der Port sein, auf dem dein Java-Programm lauscht. Die Beispiele nutzen 8080. Änderst du ihn (Umgebungsvariable PORT), ändere ihn auch im Befehl.
  4. Am Ende beide Programme mit Strg+C beenden.

Zeigt der Browser oder Telegram einen Fehler (zum Beispiel 502), läuft meist dein Java-Programm nicht oder auf einem anderen Port als dem im Befehl.

Alternativen ​

Andere Tunnel-Dienste wie ngrok erfüllen denselben Zweck. Sie sind hier nicht getestet. Mit einem eigenen Server und einem Reverse Proxy (zum Beispiel nginx oder Caddy) vor deinem Programm bekommst du eine feste Adresse, siehe Lektion 6.
