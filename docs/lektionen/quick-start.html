Quick-Start ​

In rund zehn Minuten schickst du deine erste Nachricht per curl und startest einen Echo-Bot, der alles zurückschreibt. Wie es genau funktioniert, erklären die nächsten Lektionen. Hier geht es um den schnellen Erfolg.

Voraussetzung ist das Kapitel Vorbereitung: ein Bot, sein Token in TELEGRAM_BOT_TOKEN und JDK 21.

Lernziel ​

Du hast mit curl und mit Java eine Nachricht an deinen Bot gesendet und empfangen.

curl ​

Die Bot API ist eine HTTP-Schnittstelle. Jeder Aufruf hat die Form https://api.telegram.org/bot<TOKEN>/<METHODE>.

1. Wer bin ich? getMe fragt nach dem Profil deines Bots:

bash
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getMe"

2. Schreibe deinem Bot. Öffne in Telegram den Chat mit deinem Bot, drücke auf Start und sende Hallo. Dann holt getUpdates die Nachrichten ab, die an den Bot gingen:

bash
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getUpdates"

In der Antwort steht unter "chat":{"id":...} deine Chat-ID. Merke sie dir.

3. Antworte. sendMessage schickt eine Nachricht an diese Chat-ID:

bash
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/sendMessage" \
  -d chat_id=DEINE_CHAT_ID \
  -d text="Hallo von curl"

Die Nachricht erscheint in deinem Chat.

Java ​

Derselbe Ablauf als Programm: Der Echo-Bot fragt mit getUpdates nach neuen Nachrichten und schickt jede mit sendMessage zurück. Er steht komplett in einer Datei und braucht keinen Build.

java
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Echo-Bot in einer einzigen Datei: {@code java Echo.java}.
 *
 * <p>Nur für den Quick-Start: das JSON wird mit regulären Ausdrücken gelesen. Ab Lektion 2 liest Jackson es richtig.
 */
public class Echo {

    public static void main(String[] args) throws Exception {
        String token = System.getenv("TELEGRAM_BOT_TOKEN");
        if (token == null || token.isBlank()) {
            System.err.println("TELEGRAM_BOT_TOKEN ist nicht gesetzt (siehe Kapitel Vorbereitung).");
            System.exit(1);
        }
        new Echo(token, "https://api.telegram.org").run();
    }

    private final HttpClient http = HttpClient.newHttpClient();
    private final String apiUrl;

    Echo(String token, String baseUrl) {
        // Der Token steckt im Pfad der URL: diese URL nie ausgeben oder loggen.
        this.apiUrl = baseUrl + "/bot" + token + "/";
    }

    void run() throws IOException, InterruptedException {
        String me = aufrufen("getMe", "{}");
        System.out.println("Bot läuft als @" + finden(me, "\"username\":\"([^\"]+)\""));

        long offset = 0;
        while (true) {
            // Long Polling: Telegram antwortet, sobald ein Update da ist, spätestens nach 30 Sekunden.
            String antwort = aufrufen("getUpdates", "{\"offset\":" + offset + ",\"timeout\":30}");

            // Das erste Stück ist der Antwort-Kopf, danach beginnt je Stück ein Update.
            String[] stuecke = antwort.split("\\{\"update_id\":");
            for (int i = 1; i < stuecke.length; i++) {
                String update = stuecke[i];
                offset = Long.parseLong(finden(update, "^(\\d+)")) + 1;

                String chatId = finden(update, "\"chat\":\\{\"id\":(-?\\d+)");
                // Possessive Quantoren (*+): Sonst läuft der Stack bei langen Texten über (Telegram erlaubt 4096 Zeichen).
                String text = finden(update, "\"text\":\"([^\"\\\\]*+(?:\\\\.[^\"\\\\]*+)*+)\"");
                if (chatId != null && text != null) {
                    // Der Text bleibt so, wie er im JSON stand (mit Escapes), und ist damit wieder gültiges JSON.
                    aufrufen("sendMessage", "{\"chat_id\":" + chatId + ",\"text\":\"" + text + "\"}");
                }
            }
        }
    }

    private String aufrufen(String methode, String json) throws IOException, InterruptedException {
        HttpRequest anfrage = HttpRequest.newBuilder(URI.create(apiUrl + methode))
                .header("Content-Type", "application/json")
                .timeout(Duration.ofSeconds(60))
                .POST(HttpRequest.BodyPublishers.ofString(json))
                .build();
        String antwort = http.send(anfrage, HttpResponse.BodyHandlers.ofString()).body();
        if (!antwort.contains("\"ok\":true")) {
            throw new IllegalStateException("Telegram meldet einen Fehler: " + antwort);
        }
        return antwort;
    }

    private static String finden(String text, String muster) {
        Matcher treffer = Pattern.compile(muster).matcher(text);
        return treffer.find() ? treffer.group(1) : null;
    }
}

Speichere die Datei als Echo.java oder nutze sie aus dem Repo und starte sie:

bash
java Echo.java

Sie meldet Bot läuft als @dein_bot. Schreibe deinem Bot etwas, und er antwortet mit demselben Text. Mit Strg+C beendest du ihn.

Was du hier noch nicht verstehst, kommt später

  • Warum der Bot minutenlang auf eine Antwort wartet und was offset und timeout tun: Lektion 3 (Long Polling).
  • Wie man JSON richtig liest statt mit regulären Ausdrücken, und was getMe noch kann: Lektion 2 (Einstieg).
  • Wie Nachrichten formatiert und anders verschickt werden: Lektion 4 (Nachrichten senden).

Übung ​

Sende dir selbst eine Nachricht mit curl, aber diesmal mit Formatierung. Ergänze sendMessage um -d parse_mode=HTML und verwende im Text <b>fett</b>. Prüfe in Telegram, ob das Wort fett erscheint.
